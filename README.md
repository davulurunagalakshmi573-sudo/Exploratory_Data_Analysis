# Exploratory Data Analysis on Titanic Dataset

## Objective
Perform exploratory data analysis on the Titanic dataset to understand passenger demographics, survival patterns, and missing values.

## Dataset
- Source: Titanic Dataset
- Records: 891
- Features: 12

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly

## Analysis Performed
Data Cleaning
Missing Value Handling
Statistical Summary
Survival Analysis
Passenger Class Analysis
Age Distribution
Visualizations

## Results
- Most passengers travelled in Third Class.
- More passengers did not survive than survived.
- Age contained missing values that were replaced with the mean.
- Cabin had too many missing values and was removed.
